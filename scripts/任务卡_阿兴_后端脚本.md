## 目标
写两个 Python 脚本，实现"输入地址 → 自动出报告"。

## 交付物 1：`tron_api.py`（TronGrid 取数封装）

### 输入接口（端点清单已定，见 skill references/tron-api-endpoints.md）
- `get_account(addr)` → 账户信息（创建时间/余额/权限）
  `GET https://api.trongrid.io/v1/accounts/{address}`
- `get_trc20(addr, contract=TR7NHqjeKQxGTCi8q8ZY4pL8otSzgjLj6t)` → USDT 转账记录
  `GET https://api.trongrid.io/v1/accounts/{address}/transactions/trc20?contract_address=...&limit=100&order_by=block_timestamp,desc`
- `get_trc10(addr)` → TRC-10 代币记录（BL 封条/诈骗币）
  `GET https://api.trongrid.io/v1/accounts/{address}/transactions/trc10`

### 要求
- 只用 `requests` + 标准库
- **429/401 自动重试**（2s/4s/8s 指数退避，最多 3 次）——这是踩过的坑
- 无 API key 模式可用；key 放 `config.yaml` 不硬编码
- 返回 dict，字段名与 TronGrid 原始一致（block_timestamp 毫秒、value 最小单位）
- 单文件，`python3 tron_api.py <addr>` 可命令行自测

## 交付物 2：`report_generator.py`（报告生成）

### 输入
- `csv_analyzer.py` 的输出（阿智已写好并验收，直接调用）
- `tron_api.py` 的账户信息（JSON）

### 输出
标准 Markdown 报告，结构：
```
# 冻结诊断报告
## 1. 冻结状态（BL封条/时间/金额）
## 2. 账户画像（创建/余额/权限/活跃度）
## 3. 资金流（转入/转出/TOP对手方/按天流量）

## 5. 最可疑触发交易（TxHash定位）

```

### 要求

- 关键数字带 TxHash 定位（前12+后8）
- 输出 UTF-8 中文
