## 背景

一位客户的 USDT 钱包被 Tether 冻结。客户希望了解：
1. 冻结的具体时间
2. 是哪笔交易/哪个环节触发的
3. 谁连累了谁（因果方向）
4. 还能不能申诉

---

## 调查过程与发现

### 1. 冻结时间定位（BL 封条法）

通过 TronScan 导出全量交易记录，在 transaction CSV 中找到 `BL`（BanList）标记：

| 地址 | BL 封条时间 (UTC) | BL 金额 | 解读 |
| :--- | :--- | :--- | :--- |
| 关联方 A | 2026-07-01 18:04:03 | 61.78 | 先被预警性冻结 |
| 主账户 B | 2026-08-08 21:20:36 | 484,381.99 | 后主枢纽收网 |

**关键结论：两者冻结时间差 38 天**，不是"同秒冻结同案"，因果方向是 A 先被标记、B 后被收网。

### 2. 资金流画像

对主账户 B 的全量 522 条 tokenTransfer CSV 统计：

| 指标 | 数值 |
| :--- | :--- |
| USDT 总流水 | 4,809 万 U（3 个月） |
| 转入 | 2,429 万 U |
| 转出 | 2,381 万 U |
| 日均流水 | ~50 万 U |
| 对手方 | 30+ |

**画像结论：** 这是一个**职业 OTC 资金枢纽**（承兑商热钱包），快进快出、多对手方、大额高频——天然触发 AML 风控。

### 3. 双向对手方排名（关键方法）

| 对手方 | 转入 B | 转出至 B | 定性 |
| :--- | :--- | :--- | :--- |
| X（最大上游） | 956 万 U（78笔） | 少量 | 主要上游资金对手方 |
| Y（双向） | 108 万 U（5笔） | 665 万 U（36笔） | **双向交易对手** |

**教训：** 判断资金关系前必须双向排名都算，否则会误判角色；"供血方"含因果判断，统一用「主要资金对手方」（上游/下游/双向）。

### 4. 冻结关联分析（时间邻近 ≠ 因果）

冻结前最后 72 小时逐笔排查，陈述链上事实：

- **冻结前最后大额入账 [E1]**：267,722 U（冻结前 38 小时，来源 TTu3mqj，与主账户此前无交互）
- **因果状态 [E0]**：TTu3mqj 于 2026-09-01 确认**未被官方冻结**（isBlackListed=false），无证据证明其触发冻结
- 结论：**目前只能证明资金关系，不能证明冻结因果**。该笔资金是冻结前重要事件，但"时间邻近 ≠ 因果"（铁律 #8）

### 5. 二次诈骗识别

冻结后主账户收到 5 种假代币：
- `UNFREEZE TG:UFT6699` / `UNLOCK TG:@Unfreeze_Assistant_Bot` / `UNBANNED TG:UB321G` 等
- 关联方收到 `unfrozen U JD` 假代币（symbol=U 非 USDT）

**判断：** 全部是骗子空投，诱导联系 TG 付费"解冻"。已警告客户勿理会。
